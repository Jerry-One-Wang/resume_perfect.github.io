## 内容

- 全屏动态封面与 Bing 每日壁纸
- 教育背景、研究方向、科研项目、实践经历、荣誉竞赛与技能
- 项目真实图片、证书大图查看和移动端响应式布局
- 适合浏览器打印的简历样式

## 替换项目图片

以下三个文件目前是“图片待补充”占位图。准备好新图片后，用同名 WebP 文件直接替换即可，无需修改页面代码：

- `assets/img/projects/shared-parking.webp`
- `assets/img/projects/v2x-driving.webp`
- `assets/img/projects/bim-highway.webp`

建议图片比例为 16:9，推荐尺寸 1600×900。

## 本地预览

在仓库根目录启动任意静态 HTTP 服务后访问 `index.html`。直接双击打开也能查看主要内容，但 Bing 背景的动态脚本建议通过 HTTP 服务运行。
